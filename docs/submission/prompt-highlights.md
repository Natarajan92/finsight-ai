# Agentic engineering — selected prompt iterations

Use 5–10 significant, truthful development episodes from the prompt registry. For each show:

1. **Challenge:** Concrete engineering problem and initial observation.
2. **My reasoning:** What I checked, what I expected, which approach I chose (human-authored).
3. **Key prompts:** Original prompt and follow-up improvement with prompt IDs.
4. **Before → after:** Relevant code diff, test outcome or measured evaluation change.
5. **Verification:** Actual commands/results, screenshots or experiment artifacts.
6. **Learning:** What worked, failed, and changed in the design.

Never invent missing prompts or measured performance.
